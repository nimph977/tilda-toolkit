# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | yes |
| < 0.1 | no |

## Reporting a vulnerability

Report it privately at <https://github.com/nimph977/tilda-toolkit/security/advisories/new>. Do not open a public issue. Include the steps to reproduce, without cookies and real IDs.

## Scope

In scope:

- cookies, keys or site data leaking from a site folder into the repository, a log or command output;
- a write to a page from the protected list;
- a write without the flag that the documentation requires;
- a data path inside the repository that the check did not refuse.

Out of scope: vulnerabilities in Tilda, Google Chrome, Node.js and `playwright-core`. Report them to the owners of those products.

## Response

There is one author, so the time to answer is not guaranteed; receipt is confirmed in the advisory itself.
