# Tilda Toolkit

**Unofficial toolkit for Tilda Publishing. Not affiliated with Tilda Publishing.**
Неофициальный инструмент для Tilda Publishing, не связан с компанией Tilda Publishing.

> Локальный CLI для аккуратного редактирования страниц Tilda через ваш Google Chrome:
> снимок до правки → план операций → запись → сверка → откат по журналу.

Набор сохраняет снимки блоков до изменений, применяет план операций JSON, сверяет
результат и не публикует страницу сам по себе. Репозиторий переносимый: он не содержит
ID проектов, доменов, профилей браузера и ключей.

Внутренний API редактора Tilda не является стабильным публичным интерфейсом.
Перед работой на новом сайте сначала выполните ручную приёмку на копии страницы.

## Быстрый старт

Требования: Node.js 24+, установленный Google Chrome, доступ к проекту Tilda в Chrome.

```powershell
npm ci
Copy-Item .env.example .env      # затем впишите свои TILDA_PROJECT_ID и TILDA_PROTECTED_PAGES
node --env-file=.env scripts/tilda.mjs --help
```

## Возможности

- **Снимки и сверка** — `snapshot` до записи, `verify` после; расхождение = код выхода 1.
- **План операций JSON** — текст, поля, списки, галереи, порядок и видимость блоков.
- **Откат по журналу** — каждая запись даёт обратный план; `rollback` тем же циклом.
- **Браузер-держатель** — Chrome открыт один раз, сессия живёт между командами.
- **Перечень страниц** — `page list`: список страниц проекта без ключей API, через браузер-держатель.
- **Защита страниц** — `TILDA_PROTECTED_PAGES`, публикация только с `--confirm`.
- **Накат на живую страницу** — `promote` через бэкап-дубль с полной сверкой.
- **Поиск и замена** по локальным снимкам без сети; скриншоты, карта блоков, проверка ссылок.
- **Сборка страницы по опубликованному референсу** — слепок сайта через держатель (`reference fetch`),
  каталог полей шаблонов (`catalog capture`), план из операций `newRecord` (`reference plan`),
  тот же цикл `apply → verify`.
- **Перенос через кабинет донора** — если аккаунт донора сотрудник тестового проекта, страницы
  донора, включая архивные блоки, копируются через буфер аккаунта (`donor copy`), оформление и
  свой шрифт — из настроек донора (`donor style`), сверка с докладом на 1440 и 320 (`donor verify`),
  адреса страниц и ссылки как у донора, но на страницы копии (`donor aliases`, `donor links`),
  проверки после переноса одной командой (`donor check`), главная страница проекта — `page role --index`.
- **Скилл для агента** — [skills/tilda-manager/SKILL.md](skills/tilda-manager/SKILL.md): правка
  страницы, сборка по референсу, перенос через кабинет донора, гейты человека.

## Пример

```powershell
node --env-file=.env scripts/tilda.mjs session  --page 200002                        # вход в Tilda
node --env-file=.env scripts/tilda.mjs snapshot --page 200002                        # снимок до правки
node --env-file=.env scripts/tilda.mjs preview  --page 200002 --plan .\my-plan.json  # что изменится
node --env-file=.env scripts/tilda.mjs apply    --page 200002 --plan .\my-plan.json  # запись + verify
```

Итог `apply`: `записано, verify: 0 расхождений`. Схема плана и синтетический пример —
[skills/tilda-manager/references/plan-schema.md](skills/tilda-manager/references/plan-schema.md), [examples/basic-text-edit.json](examples/basic-text-edit.json).

## Риски и условия Tilda

- Инструмент неофициальный: Tilda Publishing его не выпускала, не проверяла и не поддерживает.
- Он работает через внутренний интерфейс редактора Tilda, который не документирован и может
  измениться без предупреждения.
- Пользовательское соглашение Tilda (п. 3.1) запрещает использовать платформу способами,
  прямо в нём не предусмотренными; работа через внутренний интерфейс может быть сочтена
  таким способом. Нарушения Tilda определяет по своему усмотрению и вправе заблокировать
  аккаунт (п. 6.4). Этот риск несёт пользователь инструмента.
- Начинайте с тестового проекта; живой сайт меняйте только после приёмки на копии страницы.
- «Tilda» — товарный знак его правообладателя; здесь название указывает только на
  совместимость.

Текст соглашения: <https://tilda.ru/ru/terms/>.

## Границы инструмента

Набор не изменяет получателей заявок форм, CRM, платежи, домены и настройки страницы — это делается
в интерфейсе Tilda вручную. Снимки служат для сверки и отката, это не экспорт сайта.
Проект донора только читается: блоки копируются в буфер его аккаунта по явному разрешению
владельца, запись идёт только в тестовый проект.
